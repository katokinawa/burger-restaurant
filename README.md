# Stellar Burgers

Веб-приложение ресторана на краю вселенной с возможностью создания заказов бургеров, отслеживания статуса заказа и управления профилем пользователя.

## Технологии

- React 18
- TypeScript
- Redux Toolkit
- React Router
- Vite
- React DnD
- Jest
- Cypress

## Функциональность

- Создание и оформление заказов бургеров
- Перетаскивание ингредиентов (drag and drop)
- Авторизация и регистрация пользователей
- Просмотр истории заказов
- Отслеживание статуса заказа в реальном времени
- Управление профилем пользователя

## Установка и запуск

### Требования

- Node.js 18.x или выше
- npm или yarn

### Шаги установки

1. Клонировать репозиторий:
```bash
git clone https://github.com/katokinawa/burger-restaurant.git
```

2. Перейти в директорию проекта:
```bash
cd burger-restaurant
```

3. Установить зависимости:
```bash
npm install
```

4. Запустить проект в режиме разработки:
```bash
npm run dev
```

5. Для сборки production версии:
```bash
npm run build
```

6. Для предпросмотра production сборки:
```bash
npm run preview
```
